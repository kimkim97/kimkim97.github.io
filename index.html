How it works

3단계면 충분합니다

코딩은 필요 없습니다. 거래소를 연결하고, 전략을 고르고, 위험 한도를 정하세요.

STEP 01

거래소 API 연결

조회·거래 권한만 허용된 API 키를 등록합니다. 출금 권한이 있는 키는 자동으로 거부됩니다.

STEP 02

전략 선택 & 백테스트

검증된 전략 템플릿을 고르고, 과거 데이터로 먼저 시뮬레이션한 뒤 실전에 투입합니다.

STEP 03

리스크 한도 설정

최대 손실, 포지션 크기, 일일 거래 횟수를 정하면 봇은 그 안에서만 움직입니다.

FAQ

자주 묻는 질문

KIMKIMTRC가 제 코인을 가져갈 수 있나요?

불가능합니다. 출금 권한이 없는 API 키만 등록할 수 있으며, 자금은 항상 고객님의 거래소 계정에 남아 있습니다.

수익이 보장되나요?

아니요. 어떤 자동매매도 수익을 보장할 수 없습니다. KIMKIMTRC는 수익 보장이 아니라 원칙에 따른 매매와 손실 관리를 제공합니다.

팀이 왜 익명인가요?

크립토 업계 특성상 핵심 인력의 신변 보호를 위해 가명으로 활동합니다. 대신 모든 정책 변경과 공지는 공식 채널에 기록으로 공개합니다.

봇을 언제든 멈출 수 있나요?

네. 대시보드의 긴급 중지 버튼으로 모든 봇을 즉시 멈추고 미체결 주문을 취소할 수 있습니다.
